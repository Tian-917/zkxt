# 常见问题

## 启动

**Q：服务启动报 `UnknownHostException: <hostname>`？**
MyBatis-Plus 的 `IdWorker` 在启动时会调 `getLocalHost()`。容器里解析不到自己主机名时会抛这个错。
处理：把服务接入同一个 bridge 网络，或启动时 `--add-host <hostname>:127.0.0.1`。

**Q：15 个服务同时启动，有几个起不来？**
8G/2 核的机器同时拉 15 个 JVM，MySQL 默认 `max_connections=151` 会被打满，Redis 也会超时。
处理：`SET GLOBAL max_connections=500` 并写进配置文件；演示时只部署核心 6 个服务。

**Q：服务起来了但网关报 `服务不存在`？**
说明 Nacos 里还没有该服务的实例（通常是刚重启尚未注册完）。等几十秒重试，或确认 `spring.application.name` 与网关路由的 `lb://` 名称一致。

## 接口

**Q：返回 `{code:0, msg:"课程不是免费课程"}` 是出错了吗？**
不是。`code=200` 表示成功，`code=0` 是业务规则拦截（如重复签到、非免费课走免费报名），`code=400` 是参数不合法。

**Q：为什么接口返回的 `Long` 有时是字符串？**
全局把 `Long` 序列化成字符串，避免前端 JS 大整数精度丢失。服务之间的 Feign DTO 单独用 `RawLongSerializer` 保持数字，否则反序列化会变成 `null`。

**Q：播放签名返回空字符串？**
没配置云点播凭证时会走本地降级，返回空签名。配置 `zk.media.tencent.*` 后即可正常生成。

## 部署

**Q：Jenkins 构建很慢？**
Maven 首次要下全部依赖。镜像源配在 Jenkins 容器的 `~/.m2/settings.xml`，流水线里显式 `-s` 指定。

**Q：`git push` 到 GitHub 失败（TLS 被重置）？**
如果只是 `github.com:443` 不通，可以改用 SSH（`git@github.com:owner/repo.git`），端口 22 通常可用。
